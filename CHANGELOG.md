# Changelog

## 0.1.0

- Added offline RapidOCR and optional Tesseract adapters for images and PDFs.
- Added preprocessing, PDF text extraction, receipt/VAT field rules and QR cross-checks.
- Added confidence and source-box review, duplicate detection and exact money storage.
- Added CLI, loopback review UI, four MCP tools, CSV/JSON/XLSX interchange and backups.
- Included ten generated fictional receipts and real OCR acceptance tests.
